# Grinding Yet Again

It's [GDoC week][1], started yesterday! Most of my social media might be a
plethora of updates from the event on my most noisier Atmosphere account at
[alt.jacky.wtf][2]. I've spent a lot of time as of late working with friends at
[Spinel][] on [their next generation Ruby version manager][rv] (which is a
misnomer, it does _so much more_) around a particular feature; I wrote about it
[at (short) length][blog:1].

I've been using Claude Code and Pi more often to understand the hype. I've used
it to build out [stanchion][], an itch of an idea I had with [Livtet][] for ages
but now in a prototypical form. The most interesting thing it made to create
was the sigstore integration and the HTTP serving aspects so you get a
Rust-backed (supporting Python, Kotlin and Swift) plugin index for Lua-based
and WASM-based plugins for free. I'm still running security checks on it and
introducing fuzz testing but I think it's pretty decent for its offerings.

[livtet]: https://livtet.olamaelcu.net
[stanchion]: https://stanchion.jacky.wtf/
