Livtet

A tool for managing one's collection of books and information around said collections. The source code for the project is available on sourcehut.

Goals

  • Whole library search
  • Access external libraries like:
    • those held in Calibre
    • libro.fm
    • Hoopla
    • OpenLibrary
  • Tagging of material
  • Reading lists
  • Annotation management
  • Metadata discovery
  • Progress synchronization with
    • KOReader
    • IndieBookClub
    • StoryGraph
    • Goodreads
    • Bookwyrm
  • Web interface
    • Quotebacks/oEmbed-like support for content from one's library
  • OPDS 1.2 provider
  • Extensible plugin system
    • supporting those written in Lua
    • and written in JavaScript
  • Synchronization of data between compatible clients

Things I do not foresee Livtet handling would be explicitly opening and viewing books. There's excellent projects for that like Foliate, KOReader and Aldiko for that.

This is a loose list subject to change. I'm open to suggestions for them; of which you can e-mail to the tracker.
