A comment on [the Fediverse][1] prompted this post about what things I'd like
to see in GNOME Software. I try to use more of the graphical applications on my
machine nowadays and working directly with the GUI always tends to _feel_
slower than working in the terminal. The perception is largely in experience
&mdash; I know what to see when a task is done when working with packages and I
_feel_ like I have more control over what I'm doing with it.
