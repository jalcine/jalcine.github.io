I'm working on a revamp of [this worry stone of a website][1] and one thing I've
enjoyed doing is using custom elements[^1]. My example of them is something you
might see already on this page and other places &mdash; a means of showing
fixed time in relation to the timezone of the user agent (web browser).

[1]: https://ethanmarcotte.com/wrote/let-a-website-be-a-worry-stone/

[^1]:
    Mozilla has a pretty comprehensive introduction to writing your own at
    <https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements>.
    Dave Rupert has a good blog post explaining how to get more metadata for custom
    elements to get one hyped up on using them in everyday, framework-less (or
    not!) work at
    <https://daverupert.com/2025/10/custom-elements-manifest-killer-feature/>.
